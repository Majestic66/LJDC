# Images des Jeux

## Organisation des dossiers

- **enfants/** : Images d'aperçu pour les jeux enfants
  - bowling-slots.webp
  - plinko.webp
  - boites-carlos.webp

- **adultes/** : Images d'aperçu pour les jeux adultes
  - laser-game.webp
  - billard.webp
  - realite-virtuelle.webp

## Format requis

- Format : **.webp**
- Dimension recommandée : **600x400 pixels**
- Optimisé pour les aperçus de jeux

## Comment utiliser

1. Placez vos images .webp dans les dossiers correspondants
2. Les images seront automatiquement chargées par l'application
3. Rafrîchissez la page pour voir les changements
